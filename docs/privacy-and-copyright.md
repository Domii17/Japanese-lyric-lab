# 隐私与版权

## 隐私

- 项目不创建用户数据库。
- 不保存输入歌词、解析结果或用户 API Key。
- 基础拆解会把文本发送到当前部署的 `/api/analyze`，由服务器内的 Kuromoji 处理。
- 歌词搜索会将歌名或歌手发送到 iTunes Search API 和 LRCLIB。
- 开启 AI 后，只有用户主动解析的单句和对应词元会发送到所配置的 AI 服务。

不同部署者可以使用不同的隐私政策、日志策略和服务条款；公开部署前请自行补充运营者信息。

## 歌词版权

本项目不附带完整的受版权保护歌词，也不建立公开歌词库。歌词可能来自用户输入或第三方 LRCLIB，相关文字、歌曲和录音的权利归各自权利人所有。

请勿将未经授权的完整歌词或导出图片用于公开传播、商业用途或再分发。部署者应遵守所在地法律以及第三方服务条款，并提供版权投诉、纠错和下架渠道。
